# serializers

**Стек:** Django / Django REST Framework

## Структура
- `apps`
- `core`
- `db.sqlite3`
- `manage.py`
- `requirements.txt`

## Запуск
```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
